# Musica de Rota Brava (RB-R1)

`compose.py`: partitura em codigo -> MIDI (mido) -> FluidSynth 2.6.3 com SoundFonts **CC0** da FreePats -> mixagem
propria -> loops com a cauda dobrada no inicio (emenda continua; medida em `generated.json`). Composicao original.

**Tema da equipe** (F maior): `C5 F5 A5 G5 C6`, ritmo colcheia-colcheia-seminima-colcheia-seminima pontuada.

| faixa | forma | bpm | duracao |
|---|---|---|---|
| theme_explore (WAV, compat. com a demo de referencia) | 32 compassos: A B (marimba) A' B' (kalimba + metais, percussao mais cheia) | 112 | 68,6 s loop |
| theme_explore_low | mesma base sem melodia/metais, passa-baixas 4,5 kHz, -23 LUFS | 112 | 68,6 s loop |
| theme_crossing | Dm, ostinato de harpa, motivo em menor | 100 | 57,6 s loop |
| theme_return | violao dedilhado, kalimba com o motivo lento | 84 | 45,7 s loop |
| theme_discovery | arpejo subindo + motivo nos metais | 120 | 5,2 s |
| theme_victory | motivo completo + acorde final | 132 | 4,6 s |
| theme_team_call | motivo rapido | 160 | 1,5 s |

Instrumentos: xilofone (baquetas medias, VCSL) no papel de marimba; ukulele; harpa como **pizzicato substituto**;
violao classico (baixo); kalimba; Synth Brass 2 como metais leves; World Percussion (cajon, conga, bongo, shaker,
pandeiro, palmas). Nao achei marimba nem cordas pizzicato com CC0 verificado: substitutos declarados.
